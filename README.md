# 夏日冥想计划21天

## 共学简介

你是否常常感到焦虑、烦躁，或觉得身心疲惫？夏日冥想计划专为想要从零开始培养冥想习惯的你设计。在21天里，每天只需15分钟冥想，再花10分钟聆听理论音频（可当播客听），你将学会如何觉察情绪、放松身体、平静内心。无论你是否有冥想经验，都能在这里找到适合自己的节奏。坚持21天，你不仅会收获更稳定的情绪、更清晰的自我觉察，还会获得一份属于自己的冥想日记，记录每天的点滴变化。和我们一起，用这个夏天开启一场与内心的对话吧！

## 共学内容 / 课程信息

### 学习目标

* 养成每日冥想习惯（连续21天）

* 学会基本冥想技巧（呼吸冥想、身体扫描、情绪觉察）

* 在冥想中提升情绪觉察力与专注力

* 最终产出：坚持21天冥想并每日记录感受（心理变化、身体感受、情绪觉知）

### 每周安排

#### 第一周：基础建立（第1-7天）

* **学习材料**：B站李冉21天冥想课 完成 Day 1-7 的内容（[课程链接](https://www.bilibili.com/video/BV1NM4y1d7aC)）

* **每日任务**：

  1. 观看当天课程视频（约10分钟理论讲解，可当播客听）
  2. 进行15分钟冥想（跟随课程引导或自主练习）

* **交付物**：每日冥想日志（记录冥想后的身体感受、情绪变化、发现）

* **主题**：理解冥想基础，学习呼吸冥想与身体放松

#### 第二周：深入觉察（第8-14天）

* **学习材料**：B站李冉21天冥想课 跟着课程的天数进行

* **每日任务**：

  1. 观看当天课程视频（理论深化，可选）
  2. 15分钟冥想（尝试身体扫描或情绪觉察练习）

* **交付物**：每日冥想日志（重点记录情绪觉察与身体反应）

* **主题**：增强对身体和情绪的敏感度，学会与不适感共处

#### 第三周：整合巩固（第15-21天）

* **学习材料**：B站李冉21天冥想课 跟着课程的天数进行

* **每日任务**：

  1. 观看当天课程视频（总结与进阶，可选）
  2. 15分钟冥想（自由选择练习方式）

* **交付物**：每日冥想日志 + 结营总结（21天整体感受、心态变化）

* **主题**：将冥想融入日常生活，形成稳定习惯

### 学习资料

* 唯一指定课程：李冉21天冥想课（[B站链接](https://www.bilibili.com/video/BV1NM4y1d7aC)）

### 练习与反馈

* 每天完成冥想并记录日志（文字或语音均可）

* 可在共学群内自愿分享日志或感受，获得同伴支持

* 每周自行回顾日志，观察变化

注意事项

我要说的基本上全在这个 B 站的课程里面了

大家对冥想的疑惑也应该在课程里面可以解决（包括坐姿、冥想的真正实际的作用）

尽量先去开始做。上面的介绍只是一个简单大略的实施规划，不用太在意

只有你真正开始的时候，才会感受到冥想的益处，但是冥想中可能遇到一些问题，如果实在不舒服，尽量停下来（课程中亦有记载，包括可能有一些奇异的情况，不用担心，也不要有精神压力。如果身体实在感受到不舒服，就去医院。冥想是可以帮你察觉一些身体问题的）

如果是冥想的初学者，尽量跟着冥想引导课程的引导进行
